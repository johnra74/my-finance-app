# Using MyFinance

Written for the person whose money this is, not for a developer. It assumes you have used
Microsoft Money or something like it, and that you want your own records back.

Read in order the first time:

1. {doc}`installing` — there is no installer; it is one file.
2. {doc}`first-book` — creating a book, and the password decision you cannot undo.
3. {doc}`migrating` — if you have a `.mny` file, start here rather than typing anything in.
4. {doc}`backups` — before the book is worth anything to you.
