# Printing

## A register

Prints as it currently reads — **filter and all**, with the filter named on the page, so a
printed subset cannot be mistaken for the whole account.

Columns that will not fit on the paper are dropped **by priority and listed at the top**,
never silently. A printout that quietly disagrees with the screen is the failure to avoid.

## A report

The chart and the table together, paginated, with the page count stated before anything
reaches a printer.

**Bars print in one ink with their figure written beside them.** A colour printer is not a
given, and colour flattened to grey carries nothing.

## What the printed figures are

The same computed values the screen is showing — never a second formatting path that could
disagree with it.

:::{note}
Cheque printing is deliberately out of scope. Registers and reports only.
:::
