# Keyboard shortcuts

## Anywhere

| Key | |
|---|---|
| {kbd}`F1` | Open the documentation at the page about the screen you are on |

`F1` works on the unlock screen too, before any book is open, and inside the migration
wizard. The **Help** button in the top bar does the same thing, and **About** beside it gives
the version, the licence and the third-party notices.

## In a register

| Key | |
|---|---|
| {kbd}`Ctrl` + {kbd}`N` | New transaction |
| {kbd}`Enter` | Edit the selected row |
| {kbd}`Delete` | Delete the selected row |
| {kbd}`F5` | Reload |

Double-clicking a row edits it. Double-clicking a report row drills into the transactions
behind it, and double-clicking one of those lands on it in its register.

:::{note}
There is no published statement of keyboard-only, screen-reader or high-contrast support,
and no way to verify one without Windows. What *is* deliberate: every chart ships with a
table beside it, and status colours are always written out in words as well, so no figure in
this application depends on being able to see a colour.
:::
